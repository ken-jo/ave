# 비전 (Vision)

상태: 활성. 이 문서는 [영문 비전](../../vision/README.md)의 한국어 미러입니다.
Ave 가 무엇이고 어디로 가는지에 대한 정식 문장은 영문 문서 한 곳에 두고, 이
문서는 같은 내용을 한국어로 옮깁니다. 둘이 다르면 영문 문서가 기준입니다.

## 안녕하세요, Ave 입니다

*Ave* 는 라틴어로 밝은 "안녕"입니다. Ave 는 종합 에이전트 브라우저입니다.
나와 에이전트, 내가 고른 모델, 내 컴퓨터가 한자리에서 만나는 데스크톱 공간이죠.
브라우저를 열듯 Ave 를 열면, 에이전트가 웹에서, 터미널에서, 파일과 대화 속에서
내 곁에서 함께 일합니다. 매일 쓰기 편한 하나의 플랫폼 위에서요.

## 목표

아래는 제품 목표입니다. 구현한 동작과 남은 검증은 [지금의 Ave](#지금의-ave)에
따로 적습니다.

1. **나와 에이전트가 함께 쓰는 브라우저.** 에이전트가 나와 함께 브라우징합니다. 페이지를
   열고 읽고, 링크를 따라가고, 양식을 채우고, 사이트를 조작합니다. 그 브라우저는
   내 눈에 보이고 언제든 내가 넘겨받을 수 있습니다. 같은 탭을 함께 쓰므로 일을
   주고받을 때 복사·붙여넣기가 필요 없습니다.
2. **에이전트와 함께 하는 일상 터미널 작업.** 터미널은 일급 화면입니다. 여러 탭, 명령과 출력이
   블록으로 묶여 읽고 복사하고 다시 실행할 수 있는 구조, 검색 가능한 히스토리,
   그리고 일회성 명령만이 아니라 터미널 안에서 함께 일하는 에이전트.
3. **그 둘레의 모든 것을 한 플랫폼에.** 내가 고른 모델과의 채팅, 나란히 여는
   여러 대화, 파일과 미리보기, 플러그인과 마켓플레이스, 스킬, 메모리, 루틴,
   다른 기기나 에이전트에서의 원격 접근이 한 창에서 같은 프로젝트 맥락을
   공유합니다.
4. **믿고 쓰기 쉽게, 쓰기 편하게.** 중요한 동작에서는 내 의견을 묻고, 그렇지 않은
   곳에서는 방해하지 않습니다. 안전장치는 일상 사용을 편하게 하기 위해 있습니다.

## 지금의 Ave

코드와 대조해 적었습니다. 이 문서가 어긋나면 소스와 테스트가 기준입니다.

- **채팅과 병렬 작업.** 스트리밍 채팅과 재개·포크·분기·내보내기·압축, 타일로 최대
  네 개의 대화를 나란히 ([타일 채팅 그룹](../../design/tiled-chat-groups.md)),
  원하는 모델 공급자 연결.
- **작업 패널.** 타일마다 파일, 미리보기, 브라우저, 터미널, 서브에이전트, 사이드
  채팅이 한 패널에.
- **브라우저.** 에이전트가 형식이 정해진 브라우저 도구로 보이는 공유 탭을
  조작하며, `web_fetch`와 `web_search`도 사용합니다. 사람이 제어권을 넘겨받으면
  명시적으로 Resume하기 전까지 에이전트 변경 동작이 멈춥니다. 빌린 사용자 탭은
  에이전트가 놓아도 남고, 에이전트가 만든 탭도 턴이 끝나면 인계를 위해 남습니다.
  모든 모드에서 브라우저 샌드박스가 유지됩니다.
  [작업 공간 가이드](../guides/browser-terminal-workspace.md)에 페이지 조작,
  파일 선택기를 통한 업로드, 브라우저 제어와 보이는 카드 미리보기를 설명합니다.
  실제 네이티브 조작과 공급자 인증의 최종 검증은 남아 있습니다.
- **터미널.** 대화형 터미널 탭은 사용자 셸·프로필을 쓰는 **Manual · host**와
  별도 HOME·명령 블록을 가진 격리 동반 터미널 **Agent · isolated**로 나뉩니다.
  `terminal_run`은 항상 Agent를 사용하고 `terminal_read`는 각 레인과 세션을
  구분합니다. Agent 백엔드를 사용할 수 없어도 Manual은 남으며 호스트 실행으로
  대신하지 않습니다. 현재 Windows의 대화형 Agent 레인은 사용할 수 없습니다.
  실제 레인 동작 검증은 남아 있고 검색 가능한 터미널 히스토리도 아직 목표입니다.
  [작업 공간 가이드](../guides/browser-terminal-workspace.md#터미널-레인)를 참고하세요.
- **확장.** 매니페스트 기반 플러그인, 관리형 마켓플레이스, git 마켓플레이스, MCP
  서버와 MCP 앱 카드, 스킬.
- **에이전트와 원격.** 서브에이전트, 에이전트 간(A2A) 원격 접근, 헤드리스 호스트,
  메신저 앱에서의 원격 승인 (`src/main/`).
- **로컬 맥락.** 프로젝트, 메모리, Local Indexer 플러그인을 통한 로컬 색인, 루틴,
  감사 로그가 모두 `~/.ave/` 아래에 있습니다.
