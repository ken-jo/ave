# 철학 (Philosophy)

상태: 활성. 이 문서는 [영문 철학](../../vision/philosophy.md)의 한국어 미러입니다.
목표 자체는 [비전](./README.md) 한 곳에만 적고, 이 문서는 그 목표를 추구할 때
따르는 원칙을 기록합니다. 이전 판의 배경 서술과 시나리오는 git 히스토리에
남아 있습니다.

## 원칙

- **벽 뒤가 아니라 나란히.** 에이전트는 사용자가 볼 수 있는 화면에서 일합니다.
  같은 브라우저 탭, 같은 터미널, 같은 파일. 사용자는 언제든 지켜보고, 끊고,
  넘겨받을 수 있고, 에이전트는 사용자가 멈춘 곳에서 이어받을 수 있습니다.
- **한 곳, 같은 맥락.** 채팅, 브라우저, 터미널, 파일, 플러그인, 원격 세션이 하나의
  프로젝트 맥락을 공유하므로, 일이 화면 사이를 오가도 다시 설명할 필요가 없습니다.
- **내 모델, 내 컴퓨터.** 모델 공급자는 사용자가 고릅니다. 상태는 사용자 컴퓨터의
  `~/.ave/` 아래에 있고, 사용자가 살펴보고 백업하고 지울 수 있습니다.
- **계약으로 확장.** 플러그인, MCP 서버, 스킬은 공개된 계약
  (`src/plugins/types.ts`, 매니페스트, HostApi)으로 연결됩니다. 호스트에는 특정
  플러그인 전용 분기가 없습니다.
- **쓰기 편하게, 끝까지 안전하게.** 승인은 중요한 동작에서만 나타나고 그렇지 않은
  곳에서는 조용합니다. 샌드박스와 감사는 뒤에서 동작해 일상 사용을 편하게
  유지합니다 ([권한 정책](../../architecture/permission-policy-design.md)).
- **정직한 상태 표시.** 앱은 에이전트가 무엇을 하는지, 무엇을 바꿨는지, 왜
  실패했는지를 보여 주고, 실패를 기본값 뒤에 숨기지 않습니다.
