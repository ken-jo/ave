# Ave 한국어 문서

**안녕하세요, Ave 입니다.** Ave 는 종합 에이전트 브라우저입니다. 목표와 현재 상태는 [비전](./vision/README.md) 한 곳에 정리되어 있습니다.

문서의 기준은 영문입니다. 전체 문서 지도는 [영문 문서 색인](../README.md)에 있고, 이 디렉터리에는 한국어 독자나 테스트가 필요로 하는 페이지만 남깁니다. 영문 페이지와 한국어 페이지가 다르면 영문 페이지와 소스 코드가 기준입니다.
