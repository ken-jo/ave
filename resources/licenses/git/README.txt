Ave packages git 2.53.0 on Windows and Linux from the dugite-native v2.53.0-4
release archives (https://github.com/desktop/dugite-native/releases/tag/v2.53.0-4).

- git (https://git-scm.com) is distributed under the GNU General Public
  License version 2: COPYING, copied unchanged from LICENSE.txt in the
  Windows archive. Its source is at https://github.com/git/git/tree/v2.53.0,
  and the build recipe for the archives at
  https://github.com/desktop/dugite-native/tree/v2.53.0-4.
- The Windows archive also carries the license notices of the components it
  ships, under its usr/share/licenses and mingw64/share/licenses folders;
  they stay in the packaged copy.
- Ave runs git as a separate program and does not link to it.
